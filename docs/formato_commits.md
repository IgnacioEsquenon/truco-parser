# Formato de commits

tipo: descripción breve

## Tipos
- feat: Nueva funcionalidad (código del lexer, parser, etc.)
- fix: Corrección de un error o bug
- docs:	Cambios en documentación (informe, bitácora, README)
- test:	Agregado o modificación de casos de prueba
- chore: Tareas de organización, configuración, estructura
- refactor:	Reestructuración de código sin cambiar funcionalidad

## Reglas
1. Todo en minúsculas.
2. Sin punto final.
3. Describir qué se hizo, no cómo.
