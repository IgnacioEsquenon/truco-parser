## Descripción

Este proyecto implementa un analizador léxico-sintáctico para un lenguaje formal de dominio específico que describe rondas válidas del juego de cartas Truco. El sistema recibe una cadena de texto con la secuencia de cantos y resultados de una ronda, y determina si es sintácticamente válida, generando un árbol sintáctico abstracto (AST) en caso afirmativo o reportando errores en caso contrario.

## Estructura del proyecto

- `src/` - Código fuente (lexer, parser, punto de entrada)
- `tests/` - Casos de prueba válidos e inválidos
- `docs/` - Documentación e informes
- `presentacion/` - Presentación para la exposición oral
